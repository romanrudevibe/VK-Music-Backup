# VK Music Backup

Бесплатное расширение Chrome для сохранения собственных добавленных аудиозаписей VK и экспорта списка треков для переноса в Spotify. Разрабатывается и проверяется на macOS. Текущая версия: **0.1.19**.

## Скачать и установить

Откройте [последний релиз](https://github.com/romanrudevibe/VK-Music-Backup/releases/latest) и скачайте **vk-music-backup.zip** из Assets. Не выбирайте автоматически созданный архив Source code (zip): это весь проект.

1. Распакуйте ZIP в постоянную папку.
2. Откройте `chrome://extensions`, включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение».
4. Выберите вложенную папку **vk-music-backup**, где находится `manifest.json`.
5. Откройте «Мою музыку» VK в Chrome. В расширении подключите VK, соберите список и начните с «Проверить 3 трека».

Из исходников для установки выбирайте **extension/**, а не корень репозитория.

При обновлении поставьте очередь на паузу, замените файлы в **прежней установленной папке**, затем нажмите «Перезагрузить» в карточке расширения и заново откройте очередь. **Не удаляйте расширение**, если нужна локальная история загрузок.

## Возможности

- Вся коллекция собственных добавленных треков, без обхода альбомов и чужих плейлистов.
- Очередь, пауза, докачка и восстановление прогресса в браузере.
- MP3 и M4A без перекодирования, корректная кириллица.
- Подключение через открытую вкладку VK; одно обновление параметров при `bad_hash`.
- До четырёх HLS-фрагментов одновременно; треки сохраняются последовательно.
- TXT «Исполнитель - Название» для переноса списка в Spotify. Автоматического импорта в Spotify нет.
- Кнопка «Открыть папку скачанных» для текущего аккаунта; без подходящей записи в истории Chrome открываются обычные загрузки.
- Обратная связь через редактируемый черновик GitHub Issue.

Пользователь подтвердил работу версии 0.1.18 в Chrome. Автоматические проверки описаны ниже и не заменяют проверку на реальном аккаунте VK. Формат и ограничения VK могут измениться. Используйте расширение для записей, которые вправе сохранять.

## Если VK возвращает код 3

Оставьте одну вкладку VK, обновите её, проверьте воспроизведение музыки, выполните требуемый вход или проверку и подключите расширение снова.

Кнопка «Сообщить о проблеме» готовит черновик с версией и кодом ошибки. Можно отредактировать текст перед отправкой. Расширение не отправляет сообщения автоматически. Не публикуйте в Issues музыку, cookies, ключи, данные входа и личные диагностические отчёты.

## Конфиденциальность

Очередь, HLS-кэш и история скачанного хранятся локально в браузере. Для работы используются открытая вкладка VK и аудиосерверы VK. Расширение не извлекает пароли или cookies и не отправляет автору аккаунты, музыку, список треков или статистику использования.

Ссылки на GitHub, CloudTips и партнёрский сайт открываются по действию пользователя; на внешних сайтах действуют их собственные правила обработки данных.

В проекте есть отдельный сервер будущей страницы скачивания. Его счётчик хранит только дату, число открытий страницы и число запросов ZIP; без cookies, IP и идентификаторов посетителей. Повторы и боты учитываются. Это не число уникальных людей и не число установок. Сайт и этот счётчик пока не опубликованы; скачивания GitHub Releases учитываются самим GitHub.

## Разработка и сборка

Требуются Node.js и Python 3.9+.

```sh
npm ci
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
npm run build
```

ZIP появится в `releases/`. Предыдущие локальные релизы сохраняются для отката; содержимое этой папки не входит в Git. Серверные тесты открывают временный порт только на `127.0.0.1`.

Ссылка GitHub для обратной связи настраивается командой:

```sh
python3 scripts/configure_repo.py https://github.com/OWNER/REPOSITORY
npm run build
```

- `extension/` — расширение.
- `website/` — страница скачивания и сервер агрегированной статистики.
- `tests/` — автоматические проверки и лицензированная AAC-фикстура mux.js.
- `scripts/` — сборка и настройка ссылки GitHub.
- [Размещение страницы](docs/hosting.md).
