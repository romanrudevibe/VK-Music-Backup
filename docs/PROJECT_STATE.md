## Принятые решения

- macOS, расширение Chrome; только собственные добавленные аудиозаписи, без альбомов.
- Хранить очередь и HLS-кэш в IndexedDB. Не терять историю скачанного при обновлении.
- Desktop-запросы через открытую вкладку VK с проверкой совпадения аккаунта. Cookies/пароли не извлекать.
- bad_hash: обновить параметры трека из собственного списка и повторить один раз. Code 3 требует проверки живой сессии, не пропускать как недоступный трек.
- Четыре HLS-фрагмента одновременно; треки остаются последовательными, пауза между ними прежняя.
- TXT экспорт: одна строка «Исполнитель - Название», UTF-8, все треки независимо от фильтра.
- Stadika: ROMAN, скидка 500 ₽ (4900 → 4400), разовый платёж. Не писать сумму вознаграждения автора; формулировка «получает бонус». Ссылка: https://university.stadika.ru/ai-academy/?ref=ROMAN.
- Фидбек через GitHub Issues. Репозиторий: https://github.com/romanrudevibe/VK-Music-Backup. Никогда не отправлять сообщения за пользователя автоматически.
- Статистика — только посещения будущей страницы скачивания, а не телеметрия расширения. Дневные открытия и запросы ZIP, Москва; закрытый `/admin`, CSV. Не заявлять число уникальных людей.
