# VK Music Backup 0.1.19

Расширение Chrome для сохранения собственных добавленных аудиозаписей VK и экспорта списка треков для переноса в Spotify. Бесплатно, без отправки списка музыки автору.

## Скачать и установить

1. Скачайте **vk-music-backup.zip** из раздела Assets этого релиза. **Source code (zip)** — архив исходников всего проекта, для установки используйте vk-music-backup.zip.
2. Распакуйте ZIP в постоянную папку.
3. Откройте `chrome://extensions` и включите режим разработчика.
4. Нажмите «Загрузить распакованное расширение» и выберите вложенную папку **vk-music-backup**, в которой лежит `manifest.json`.
5. Откройте «Мою музыку» VK, подключите VK в расширении, соберите список и нажмите «Проверить 3 трека».

При обновлении поставьте очередь на паузу, замените файлы в прежней установленной папке и нажмите «Перезагрузить» в карточке расширения. Не удаляйте расширение: удаление может стереть локальную очередь и историю.

## Возможности

- Сохранение MP3 и M4A без перекодирования; до четырёх HLS-фрагментов одновременно.
- Очередь, пауза, продолжение, локальная история скачанного.
- Обновление параметров трека при `bad_hash`.
- Экспорт TXT «Исполнитель - Название».
- Открытие папки скачанных файлов текущего аккаунта.
- Добровольная [поддержка автора](https://pay.cloudtips.ru/p/176d0656).
- «Сообщить о проблеме» открывает редактируемый черновик GitHub Issue. Отправку подтверждает пользователь.

## Проверка и ограничения

Пользователь подтвердил работу версии 0.1.18 в Chrome. В 0.1.19 подготовлены публикация и ссылка GitHub для обратной связи; работа с VK и хранение очереди сохранены. Новую версию отдельно в живом VK не проверяли.

Используйте расширение для записей, которые вправе сохранять. Формат и ограничения VK могут измениться. Расширение не выполняет автоматический импорт в Spotify и не размещено в Chrome Web Store.

Не прикладывайте к публичным Issues музыку, cookies, ключи, данные входа и личные диагностические отчёты. Достаточно версии расширения, кода ошибки и описания действий.
