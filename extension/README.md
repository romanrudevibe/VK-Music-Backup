# Мои аудиозаписи — резервная копия

Расширение Chrome для macOS, версия 0.1.15.

## Параллельная загрузка фрагментов — версия 0.1.15

До четырёх HLS-фрагментов одной записи скачиваются одновременно. Сборка сохраняет порядок плейлиста, независимо от порядка завершения запросов. Получение ключа AES совместно используется параллельными загрузками; расшифровка учитывает номер каждого фрагмента. Готовые фрагменты сохраняются для докачки. При паузе или ошибке запросы отменяются, и завершение всех работников ожидается до выхода из текущей загрузки.

Подключение через вкладку VK, автоматическое обновление параметров при bad_hash, обработка недоступных записей, пауза между треками и последовательная очередь треков не изменены. Новые разрешения не нужны. Прямое скачивание MP3 работает как раньше.

Прошли 10 автоматических проверок: перекрытие четырёх запросов, порядок сборки, AES с общим ключом и разными IV, пауза/докачка, остановка при ошибке, обновление параметров bad_hash и существующие проверки очереди и M4A. Реальное ускорение зависит от аудиосервера и соединения и пока не измерено.

Перед обновлением поставь очередь на паузу. Замени файлы в прежней папке, обнови карточку расширения, заново открой страницу очереди и проверь номер 0.1.15. Оставь вкладку VK открытой, нажми «Проверить 3 трека», затем продолжи загрузку. Уже сохранённые файлы и фрагменты сохраняются. Архив 0.1.14 оставлен для возврата к предыдущей версии.

## Обновление параметров доступа — версия 0.1.14

При получении bad_hash расширение обновляет параметры конкретного трека из собственных аудиозаписей и повторяет получение ссылки один раз. История скачанных файлов сохраняется. Для вновь собранных записей сохраняется позиция страницы; для старых записей поиск начинается с первой страницы и следует серверной пагинации. Поиск ограничен 100 страницами. Повторный bad_hash останавливает очередь, а не помечает запись недоступной.

После замены файлов и обновления карточки расширения заново открой очередь: вверху должна быть версия 0.1.15. Оставь «Мою музыку» открытой и нажми «Проверить 3 трека». Автоматические проверки обновления параметров, пагинации, ограничения повторов и очереди прошли. Работа на реальном аккаунте после исправления ещё не проверена.

## Экспорт списка для Spotify — версия 0.1.8

В разделе «Аудиозаписи» добавлена кнопка **«Сохранить список треков для импорта в Spotify»**. После полного сбора списка она сохраняет `vk-tracks-for-spotify.txt` в UTF-8. Формат:

```text

```

Каждая аудиозапись занимает одну строку. В файл входят все треки из локального собранного списка — скачанные, ожидающие и с ошибками, независимо от поиска, фильтров и текущей страницы. При обновлении замени файлы в прежней папке, нажми круглую стрелку на карточке расширения в `chrome://extensions` и заново открой страницу расширения. Если список уже собран, пересобирать его не нужно.

## Установка — один раз

1. Распакуй `vk-music-backup.zip`. Помести папку `vk-music-backup` в постоянное место, например в «Документы». Не перемещай её после установки.
2. В адресной строке Chrome введи `chrome://extensions`.
3. Включи **Режим разработчика** справа вверху.
4. Нажми **Загрузить распакованное расширение**.
5. Выбери папку `vk-music-backup`, внутри которой находится `manifest.json`.
6. Открой меню расширений (значок пазла) и нажми **Мои аудиозаписи — резервная копия**. Откроется страница очереди.

Устанавливается только расширение: Terminal, Python, Node.js и отдельная программа не нужны.

## Первая проверка

1. Оставь открытой вкладку VK, где ты вошёл в свой аккаунт. Открой «Музыка» → «Моя музыка».
2. На странице расширения нажми **Подключить VK**. Должен появиться числовой ID твоего аккаунта.
3. Нажми **1. Собрать список**. Дождись надписи **Список собран**. На этом шаге аудиофайлы не скачиваются.
4. Проверь, что количество соответствует твоим добавленным аудиозаписям. Нажми **2. Проверить 3 трека**.
5. Проверь три сохранённых файла и их воспроизведение. После этого нажми **Скачать всё / продолжить**.

Если на любом шаге ошибка — нажми **Скачать отчёт об ошибках** и передай отчёт разработчику. В отчёте нет cookies, пароля, ID аккаунта, названий треков или временных ссылок.

Если подключение не удалось, передай текст ошибки: отчёт не содержит ошибки определения аккаунта, которые возникают ещё до запуска очереди.

## Как это работает

- Получает именно общий список добавленных аудиозаписей текущего пользователя (`playlist_id=-1`). Отдельные альбомы, рекомендации и чужие плейлисты не обходятся. Трек из альбома, который ты отдельно добавил в свои аудиозаписи, остаётся в списке.
- Собирает список порциями до явного ответа VK, что продолжения больше нет. В расширении нет лимита 1000 и не нужно выделять треки вручную.
- Сохраняет очередь и позицию в локальной базе после каждой порции. При неожиданном формате ответа останавливается и не объявляет список полным.
- Скачивает последовательно, с паузами между запросами и максимум тремя попытками на трек. Недоступные записи остаются в списке ошибок.
- Готовые записи пропускаются, пока сохранены данные расширения. Существующие файлы не перезаписываются. Если такая папка заполнялась другой программой, её файлы автоматически не сопоставляются.
- «Обновить список» перечитывает коллекцию с начала, сохраняя историю скачанного. Ранее найденные записи, удалённые из VK, остаются в локальной очереди резервной копии.

## Докачка и пауза

- **Пауза** останавливает очередь и сохраняет прогресс.
- Для прямых MP3 используется механизм докачки Chrome. Когда сервер не позволяет продолжить или ссылка истекла, расширение получает свежую ссылку и заново загружает только текущий трек.
- Для HLS сохраняются целые полученные сегменты. После обрыва повторно скачивается только незаконченный сегмент; готовые переиспользуются, если структура потока совпадает. Если VK изменил структуру или пути сегментов, текущий трек собирается заново.
- Закрытие страницы очереди не ставит загрузку на паузу. После перезапуска Chrome активная очередь автоматически продолжится. Во время сна Mac и при закрытом Chrome загрузка не идёт.
- Не удаляй расширение, его данные или историю загрузок Chrome до окончания очереди. Это может лишить программу информации для докачки. Сами готовые аудиофайлы расширение не удаляет.

## Файлы и качество

Папка: **папка загрузок Chrome → VK Audio → ID аккаунта**.

Имена: `Исполнитель — Название [ID трека].mp3` либо `.m4a`. ID различает версии с одинаковым названием. Кириллица поддерживается.

Прямые MP3 сохраняются без перекодирования. HLS с AAC собирается в M4A без перекодирования и без искусственного увеличения битрейта. Поддержаны обычные завершённые HLS-потоки, AES-128, MPEG-TS/AAC и fMP4. DRM, SAMPLE-AES и потоки с разрывами не поддержаны; такие записи показываются с ошибкой. Обложки, встроенные теги и тексты песен эта версия не добавляет.

Временные сегменты хранятся в профиле Chrome, а после успешного сохранения трека удаляются. Во время сборки нужно свободное место и для временных частей, и для готового файла.

## Если не работает

- **Не определён аккаунт:** обнови открытую страницу VK и снова нажми «Подключить VK». Если ошибка сохраняется, потребуется подстроить определение пользователя под текущую версию сайта.
- **VK вернул страницу вместо списка:** открой `https://m.vk.ru/audio` (или `https://m.vk.com/audio`, если подключён vk.com) в том же профиле Chrome и проверь вход. Затем продолжи сбор списка. Пароль вводится только на странице VK.
- **VK отклонил запрос / 429:** проверь страницу VK, подожди и продолжи. Расширение не решает проверки сайта автоматически.
- **Не распознан формат / повторяется страница:** список может быть неполным. Пришли отчёт; нужен ремонт адаптера VK.
- **Неподдерживаемый адрес аудиосервера:** пришли текст ошибки. Для нового CDN потребуется добавить точный домен и обновить расширение.
- **Ошибка записи файла:** проверь свободное место и `chrome://downloads`.
- **Запрос выбора места для каждого файла:** расширение задаёт `saveAs:false`. Проверь настройки загрузок Chrome и другие расширения, которые могут менять поведение сохранения.
- **Файл удалён вручную после успешного скачивания:** расширение не пересканирует диск и продолжает считать запись сохранённой. Автоматического восстановления вручную удалённых готовых файлов в этой версии нет.

## Доступы

Расширение читает ID вошедшего пользователя во вкладке VK, запрашивает список и ссылки с использованием сессии браузера, управляет только собственными загрузками. Пароль и cookies не извлекаются и не сохраняются в файлах расширения. Нет аналитики, рекламы и стороннего сервера. Запросы идут в VK и на разрешённые аудиосерверы. Библиотека сборки аудио включена в архив, удалённый код не подгружается.

`unlimitedStorage` используется для большой очереди и временных аудиосегментов; `offscreen` — для сборки M4A; `alarms` — для восстановления фонового процесса; `downloads` — для сохранения и докачки; `scripting` — для чтения текущего ID VK. Расширение не просит доступ ко всем сайтам.

## Проверки и исходники

Все исходники находятся рядом с этим файлом. Проверки парсеров и имён файлов: `npm test` (нужен Node.js, только для разработки).

В ходе сборки также выполнены интеграционные проверки с имитацией Chrome/IndexedDB: 1003 трека, обновление списка, предел проверки в три трека, пауза/возобновление, восстановление загрузки после сбоя между созданием файла и сохранением ID; кэширование AES-128 HLS-сегмента после прерывания. Собранный тестовый M4A распознан macOS `afinfo`: AAC, стерео, 44,1 кГц, 9,94 секунды.

Установка в Chrome, вид интерфейса, реальные ответы VK, полнота твоей коллекции и реальные загрузки из VK **ещё не проверены**. Эта сборка — основа для первой проверки и последующей настройки, а не подтверждение совместимости с текущим VK.
