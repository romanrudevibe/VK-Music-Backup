# VK Music Backup 0.1.19

## Установка

В Chrome откройте `chrome://extensions`, включите режим разработчика и нажмите «Загрузить распакованное расширение». Выберите эту папку, содержащую `manifest.json`.

Откройте «Мою музыку» VK, подключите VK, соберите список и начните с «Проверить 3 трека». При обновлении заменяйте файлы в прежней установленной папке и обновляйте карточку расширения. Не удаляйте расширение, если нужна история загрузок.

## Скачать и сообщить о проблеме

Релизы: https://github.com/romanrudevibe/VK-Music-Backup/releases/latest

Проблемы: https://github.com/romanrudevibe/VK-Music-Backup/issues

Кнопка «Сообщить о проблеме» открывает редактируемый черновик. Отправку подтверждает пользователь. Не публикуйте музыку, личные диагностические отчёты и данные входа.

## Конфиденциальность

Очередь, части аудио и история скачиваний хранятся локально в браузере. Расширение не отправляет автору аккаунты VK, музыку или статистику использования. Внешние ссылки открываются по действию пользователя; платёжные данные обрабатывает CloudTips.
